1 Sign in to Canva
How to copy the right cookies
  1. Open canva.com while signed in
  2. DevTools (F12) → Network → reload
  3. Click any canva.com request
  4. Under Request Headers, copy the whole Cookie: line

A cookies.txt export works too. Don't use document.cookie — the session cookie is httpOnly and won't be there.

Signs in through Canva's own login page in the browser window. Canva often prefers a one-time code over a password — if it does, you'll be asked for the code it emails you.
